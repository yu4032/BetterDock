# 10×6 Home Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a selectable 10×6 landscape / 6×10 portrait grid while preserving stock and existing 8×4 / 4×8 behavior.

**Architecture:** Add a canonical `home_grid_extended` master switch plus a `HomeGridProfile` persisted as `grid_profile`. Migrate the legacy `home_grid_8x4` boolean into these two settings, then pass `enabled + profile` through `LiquidDockConfig` and `MainHook` into `HomeGridHook`. Generate rotation metadata from even 2×2 blocks instead of hard-coded 8×4 coordinates.

**Tech Stack:** Android Java/Kotlin, libxposed hooks, Jetpack Compose, Miuix KMP preferences, JUnit 4, GitHub Actions Gradle build.

## Global Constraints

- Master switch off means completely stock MIUI grid behavior.
- Existing `home_grid_8x4=true` migrates to enabled + `8x4`.
- Profile selector contains only `8x4` and `10x6`; stock is represented only by the master switch being off.
- 10×6 means landscape 10×6 and portrait 6×10.
- Preserve dedicated workstation All Apps geometry.
- Keep widget support limited to 1×1, 2×1, 2×2, and 4×2.
- Do not add delayed layout work beyond existing behavior.
- Do not implement the folder-close blur fix in this branch.
